Exercise: query02
----------------------

### Description

Write a function that receives a `Pencil` object as a parameter and returns the
number of leads in that pencil.

### Function Name

query02

### Parameters

* `pencil`: A `Pencil` object

### Return Value

The number of leads in `pencil`.

### Example

    import pencil
    p = pencil.Pencil(3)
    print(query02(p)) # -> 3
