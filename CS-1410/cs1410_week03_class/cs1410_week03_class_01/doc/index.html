Exercise: create01

Description

Write a function that receives no parameters and returns a Pencil object constructed with 3 leads.

Function Name

create01

Parameters

  • None

Return Value

A Pencil object with 3 leads.

Example

p = create01()
print(p.get_num_leads()) # -> 3
print(p.get_current_lead_length()) # -> 10

Hints

  • Don't forget to import Pencil.
